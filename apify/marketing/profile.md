# Профиль разработчика на Apify

Куда вставлять: Apify Console → Settings → Profile. Короткое описание идёт в поле Bio, длинный текст — в описание профиля (README), туда, где сейчас стоит список из 10 акторов.

## Bio

```
Clean data APIs: 18 job sites and ATS (LinkedIn, Indeed, Glassdoor, Foundit, Xing…) in one format, Redfin homes, Google Play and Google News.
```

## Описание профиля

Apify разрешает не больше 2000 знаков; этот текст — 1994 знака (обновлён 14.10: Wellfound, Xing, Foundit и почта поддержки).

```markdown
### Clean data from job sites, real estate and app stores

Public websites as clean, structured data: numbers as numbers, the same fields across sources. Pay only for results, no start fees.

**Jobs**, one output format for all sites:

- [All-in-One Jobs Scraper](https://apify.com/robertosan16/all-in-one-jobs-scraper): many job sites in one search
- [LinkedIn](https://apify.com/robertosan16/linkedin-jobs-scraper), [Indeed](https://apify.com/robertosan16/indeed-jobs-scraper), [Glassdoor](https://apify.com/robertosan16/glassdoor-jobs-scraper), [Dice](https://apify.com/robertosan16/dice-jobs-scraper), [Wellfound](https://apify.com/robertosan16/wellfound-jobs-scraper) (startups)
- Europe: [Xing](https://apify.com/robertosan16/xing-jobs-scraper), [StepStone](https://apify.com/robertosan16/stepstone-jobs-scraper), [Reed](https://apify.com/robertosan16/reed-jobs-scraper), [InfoJobs](https://apify.com/robertosan16/infojobs-jobs-scraper), [Welcome to the Jungle](https://apify.com/robertosan16/welcome-to-the-jungle-jobs-scraper)
- Asia, Gulf, Pacific: [Foundit](https://apify.com/robertosan16/foundit-jobs-scraper), [SEEK](https://apify.com/robertosan16/seek-jobs-scraper), [Jobstreet](https://apify.com/robertosan16/jobstreet-jobs-scraper), [JobsDB](https://apify.com/robertosan16/jobsdb-jobs-scraper)
- Career sites: [Greenhouse](https://apify.com/robertosan16/greenhouse-jobs-scraper), [Lever](https://apify.com/robertosan16/lever-jobs-scraper), [Ashby](https://apify.com/robertosan16/ashby-jobs-scraper), [Workday](https://apify.com/robertosan16/workday-jobs-scraper)

**Also**: [Redfin](https://apify.com/robertosan16/redfin-scraper) (US homes), [Google Play](https://apify.com/robertosan16/google-play-scraper), [Google News](https://apify.com/robertosan16/google-news-scraper)

**Why these Actors**

- Only new records since the last run, for daily alerts
- Make, Zapier, n8n and AI agents (MCP)
- Need a field or a custom scraper? Open an issue or email support@mozartstandard.com
```
